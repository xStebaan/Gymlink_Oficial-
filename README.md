# Gymlink_Oficial-
Sistema integral de gestión para gimnasios y centros deportivos: control de membresías, agendamiento de clases y administración de entrenadores en un solo lugar.

### 🎯 Product Goal (Meta del Producto)

**"Aumentar la rentabilidad y retención en los gimnasios motivando la asistencia constante de los socios a través de un sistema dinámico de check-ins, rachas y recompensas canjeables."**

### 🚀 Objetivo del Sprint 1 (Sprint Goal)

**"Consolidar y dejar al día toda la documentación técnica y funcional del proyecto GymLink, y dar inicio a la implementación base de la aplicación web en Spring Boot (configuración inicial del entorno, estructura del proyecto y arquitectura base)."**
