# Gymlink_Oficial-
Sistema integral de gestión para gimnasios y centros deportivos: control de membresías, agendamiento de clases y administración de entrenadores en un solo lugar.

### 🎯 Product Goal (Meta del Producto)

&gt; **"Aumentar la rentabilidad y retención en los gimnasios motivando la asistencia constante de los socios a través de un sistema dinámico de check-ins, rachas y recompensas canjeables."**

### 🚀 Objetivo del Sprint 1 (Sprint Goal)

&gt; **"Construir la base del sistema y maquetar la interfaz principal de GymLink, habilitando la autenticación segura por roles (Socio/Admin/Coach) y las vistas clave para el control de asistencia y puntos."**
